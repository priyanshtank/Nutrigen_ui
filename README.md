# 📱 NutriGen UI – Flutter + Firebase App

Welcome to the NutriGen app! This project uses Flutter and Firebase for authentication and onboarding features. Follow the instructions below to set it up locally.

---

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/priyanshtank/Nutrigen_ui.git
```

To run- Use your phone device as the firebase is android compliant

🔐 Firebase Setup

Firebase files (`google-services.json`, `GoogleService-Info.plist`, and `firebase_options.dart`) are already included.

✅ No manual setup needed — just clone and run!
